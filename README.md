# ピヨンと☆飛び石 — Three.js MV Previz

`index.html` をChromeまたはEdgeで開くと、元音源に同期した16:9のThree.jsプレビズを再生できます。Three.jsと日本語WebフォントはCDNから読み込みます。

## 操作

- ▶ / Ⅱ：再生・一時停止
- シークバー、章ボタン：再生位置を移動
- ●：曲を最初から再生し、最後までリアルタイム録画して `piyon-toishi-previz.webm` を保存
- ⛶：全画面表示

録画中はタブを前面にし、シークや一時停止をせずに最後まで再生してください。録画はリアルタイムです。

## 内容

- `assets/piyon-toishi.mp3`：指定されたSuno曲の音源。実尺は2:11.54。
- `index.html`：冬の高速道路、飛び石、ひびの入ったフロントガラス、車検工場、コインの演出を含む、ビビッドなポップコミック調の3Dシーン。
- 歌詞字幕、合いの手字幕、歌詞セクションごとの色・カメラ・構図切り替え。
- タイムコードは実音源をローカル音声認識し、歌唱フレーズの開始位置に合わせて再配置したプレビズ用の概略値です。合いの手や一部の発音は認識誤差があるため、フレーム単位の最終字幕ではありません。歌詞本文は依頼文の表記を使用しています。

## 演出メモ

指定された「000000_資料」のカメラ用語資料を参照し、POV、ドリーイン、トラッキング、アーク、クラッシュズーム、俯瞰、ローアングルを歌詞の場面に割り当てています。構図は額縁、奥行き、中央、放射、対角線、シルエットを使っています。Three.jsのプリミティブ形状だけで組んだ簡易3Dプレビズです。

添付された参考MV 3本はプレビューに素材として埋め込んでいません。映像クリップに依存しないよう、車・道路・飛び石の主題を新規の3Dシーンとして組み立てています。
